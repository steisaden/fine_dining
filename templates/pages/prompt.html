Brand brief

Esker is an understated chef-led practice for seasonal tasting, private tables, chef’s-table evenings, small celebrations, and culinary collaborations. It sells attention and fit—not status—and converts through an availability inquiry that never implies confirmation.

Visual direction and tokens

“The Final Millimeter” turns the chef’s pass into an interface: bone porcelain fields, charcoal and blackened steel, oxidized silver rules, dark wine, and one sorrel accent. All colors, font families, spacing intervals, rules, and motion durations are centralized in public/css/tokens.css.

Typography

Upright Bodoni 72 or Didot marks only editorial thresholds. Avenir Next carries navigation, forms, and reading copy. System monospace is reserved for course numbers, temperatures, dimensions, and service notation—not used as a luxury costume.

Route architecture

Full pages: GET /, /menu, /private-dining, /journal, /reservations, and /prompt/. Menu and service query states are directly shareable and work without JavaScript.

HTMX contract

GET /fragments/menu/:course, GET /fragments/private-dining/:service, and GET /fragments/reservation-form return focused HTML. Reservation, private-dining, and newsletter POST routes validate and persist before acknowledging receipt. The Go server uses a mode-0600 append-only store; the edge requires an INQUIRIES binding. Both fail closed and retain form entries when a write fails. HTMX swaps only the intended region, moves focus after meaningful updates, announces status, prevents duplicate submission, and pushes URLs for navigable detail states.

Scroll-video architecture

ScrollVideo reads the actual duration at loadedmetadata. ScrollTrigger supplies normalized progress; one RAF damps target time toward rendered time. Decoder seeks are thresholded, safely clamped, and single-flight, with only the newest non-stale target retained. Visibility pauses the loop. A centralized HTMX lifecycle destroys triggers, GSAP contexts, observers, timers, media listeners, resize handlers, and focus/menu listeners before replacement.

Accessibility and responsive behavior

Semantic landmarks, skip navigation, visible focus, 44px targets, real links, current-page states, controlled menu focus, Escape close, inert background, server errors, and live status regions remain independent of the film. Desktop annotations use frame negative space. At 800px and below, the film occupies 56svh and copy moves into a solid region rather than covering the plated subject.

Reduced motion and performance

Reduced motion removes the 550vh scrub, seeks a stable representative frame, and exposes all five chapters in normal document flow. The master loads only on the homepage, never duplicates a decoder, and is absent from this archive. Static caching distinguishes fingerprinted immutable files from mutable named assets. Production delivery should later add smaller adaptive variants while retaining the supplied master.

Impeccable influence

The service-ledger composition, first-viewport thesis, strict hierarchy, upright typography, asymmetric pacing, authored responsive reflow, focus and contrast floor, restrained motion, and pre-emit critique follow Impeccable. Deliberately refused: centered copy over darkened food, repetitive cards, black-and-gold shorthand, fake credentials, glass panels, generic fade-ups, ornamental diagrams, tiny labels, and an oversized booking control.
